Accessibility Statement

Last updated: September 8, 2026

Cook Better Co. aims to make its website usable by people with disabilities. The current implementation has been reviewed for common accessibility issues and has been adjusted to improve keyboard focus visibility, form labels, button naming, modal semantics, image alternative text for product images, and contrast.

Our target

We use WCAG 2.1 Level AA as a practical accessibility target for the site. The U.S. Department of Justice identifies WCAG as helpful technical guidance for businesses' web accessibility obligations.

Current improvements

  • Visible keyboard focus indicators.
  • Labels associated with the main form controls.
  • Meaningful button labels instead of icon-only controls where practical.
  • Dialog semantics and Escape-key closing for modal dialogs.
  • Alternative text for product images.
  • Color is not intended to be the only way an important status is communicated.
  • Responsive layout for smaller screens.

Known limitations

Automated checks cannot prove full accessibility. Recipe imagery used as CSS background images is not exposed as content to screen readers; those images are decorative in the current recipe cards. Dynamic content and future video lessons require additional testing, including captions/transcripts where video is introduced.

Report an accessibility problem

Publish a monitored accessibility/contact email before launch. Include the page, feature, and the assistive technology or browser involved when reporting a problem.
