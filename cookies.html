Cookie Policy

Last updated: September 8, 2026

1. What cookies are used now

The current Kroger integration uses only cookies that are necessary to provide the requested authentication flow:

  • cb_kroger_session: HttpOnly, Secure, SameSite=Lax session cookie containing an encrypted OAuth session payload.
  • cb_kroger_state: OAuth state cookie used to protect the authorization callback from request-forgery/mismatched authorization responses.

The local-profile prototype uses browser local storage, which is separate from cookies.

2. Analytics and advertising

No analytics or advertising cookies are intentionally installed by the current site. There are no Google Analytics, Meta Pixel, or advertising scripts in the current prototype.

3. Do we need cookie consent?

For the current implementation, the site is limited to cookies that are necessary for a feature the user requests (Kroger sign-in) and does not use non-essential analytics or advertising cookies. A consent banner is therefore not being used as permission to set non-essential cookies. The site does display a notice so users can understand the current cookie use.

If analytics, advertising, social pixels, personalization, or other non-essential cookies are added, the consent design must be revisited. In jurisdictions that require prior consent for non-essential cookies, those technologies should not load until the user has made the required choice.

4. Third-party requests

Recipe imagery currently loads from Unsplash, and Kroger requests are made through the site's server API. These third parties may process technical request information under their own policies.

5. Changes

We will update this policy when cookie or tracking technologies change.
